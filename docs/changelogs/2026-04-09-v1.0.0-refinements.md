# Refinamientos previos a v1.0.0

**Released:** 2026-04-09

## Summary

Ajustes que cierran la versión 1.0.0. El manejo de errores de la API se centraliza en un middleware de Express: los errores de dominio (`BaseError`) responden 400 y los demás 500, siempre registrados con el logger. Las dependencias se actualizan, incluida la migración a zod v4 y a cheerio 1.2, y se corrige el tipado de `ParseAdapter`. El README se reescribe con la arquitectura actual, los endpoints, las colecciones y los pasos de instalación, y la colección Bruno suma los endpoints de resultados.

## Highlights

- Middleware `errorHandler` en `src/api/error-handler.ts`.
- Migración a zod v4 y a cheerio 1.2.
- README reescrito con arquitectura, endpoints, requisitos y estructura del proyecto.

## Added

- `src/api/error-handler.ts`, registrado en `api/server.ts`.
- Requests `simulacros-2021-result`, `simulacros-2022-result` y `simulacros-2023-result` en la colección Bruno.

## Changed

- Las rutas delegan los errores no controlados al middleware en lugar de responderlos cada una.
- `ParseAdapter` tipa mejor su salida, lo que elimina casts en los parse adapters de la BCN.
- Dependencias actualizadas, con zod v4.
- README reescrito: arquitectura, endpoints, colecciones de MongoDB, requisitos, pasos de instalación, scripts y estructura del proyecto.

## Fixed

- El nombre `MapperAdater` pasa a `MapperAdapter`.
- `z.record()` usa la sintaxis de dos argumentos de zod v4.
- cheerio se importa como namespace, para compatibilidad con la versión 1.2.
- nodemon y puppeteer actualizados para corregir vulnerabilidades.

## Migration

- Proyectos que extiendan `IndicatorBuilder` o definan schemas con `z.record()` deben usar la sintaxis de zod v4: `z.record(clave, valor)`.
